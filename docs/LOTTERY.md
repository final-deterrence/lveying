# 无间道主题抽奖操作说明

当前使用简洁文字和色彩占位，按 PDF 安排开场、三等奖两批、二等奖、来电、一等奖、天台对峙、特等奖与互动等场景。音效、配音、视频、奖品图和精细动画需要后续接入；现场需由导播按主持词控制切换。

1. 使用 HTTPS 登录后台，在抽奖设置中确认号码范围及历史记录，点击“打开抽奖导播台”（`/admin/lottery/display`）。每个抽奖场景可以设置奖项名称和人数；本机浏览器记住设置和场景。默认人数仅为占位，可在开始前修改。
2. 点击“开始滚动”，主持人倒数后点击“确认抽取”。服务器保存结果后，屏幕在约 1 秒内从左向右将乱码变成七个问号；动画完成后，“随机揭晓下一个”每次点亮一个随机空位，“随机揭晓全部”按随机次序依次点亮剩余位置，通常约 1.2 秒完成（逐个向服务器确认，网络较慢时会延长）。已出现的号码不会移动或重复揭晓，刷新或回看场次也保留布局；升级前已开始的旧批次保留已显示位置，只打乱剩余空位。空格键依次执行开始、确认和揭晓下一个；左右方向键切换场景，H 隐藏或显示导播面板。未完成揭晓或正在自动揭晓时不能切换场景。
3. 号码由服务器随机抽取并在各批之间去重，默认中奖有效。只有现场确认单人特等奖无效时，才能在特等奖场景点击“核验无效 · 重抽”，确认作废后重新开始抽取。后台历史和导出会标注作废原因；作废号码仍不参与后续抽奖。
4. 抽奖或揭晓时网络异常，先恢复网络，再按提示重试或用同一浏览器刷新。服务器保存抽取结果和揭晓进度，请求编号保存在浏览器；不要清除浏览器数据或切换设备。若提示其他设备存在未完成的抽奖，请回原设备完成。断网时不能进行新的抽取或揭晓。
5. 观众结果页（`/lottery`）保持只显示已揭晓且有效的号码，每 5 秒更新。后台可查看及导出历史。“清空历史”会同时重置去重号码池，可能使以前的中奖号码再次被抽中；正式活动开始前如需清空测试记录，应先确认并备份。清空后刷新导播台。

导播与投影分屏：在导播台点击“打开纯净大屏”，新窗口地址为 `/admin/lottery/screen`，其中没有控制面板、控制入口或操作快捷键。电脑选择“扩展屏幕”，将新窗口移到投影屏并按 F11 全屏，导播台留在电脑上操作。场景切换、滚动、加密和随机揭晓会自动同步；打开或刷新纯净大屏也能接上当前画面。纯净窗口只接收已揭晓号码，隐藏号码不会放进展示快照。

此版本通过浏览器本地窗口通信实现分屏：两个窗口必须在同一电脑、同一浏览器配置文件、同一网站来源（协议、域名、端口完全相同）下，保持一个导播台打开。不能用手机或另一台电脑远程操作，也不要混用普通窗口与无痕窗口。关闭导播台后投影保留最后画面，直到重新打开导播台。抽取和揭晓仍需连接服务器；不需要额外部署通信服务。

联排建议：在测试数据上打开两个窗口，进入“三等奖 · 第一批”，完整执行滚动、确认、等待问号、随机揭晓一个、随机揭晓全部。确认纯净大屏没有任何按钮、揭晓前只显示问号、已出现号码保持位置；部分揭晓后刷新导播台和大屏，确认进度与位置保留。再进入用户端 `/lottery`，确认只能看到已揭晓结果。正式投影前还需在现场双屏设备上检查全屏与窗口摆放。

场景、已完成场次的回看和配置保存在操控浏览器，中奖记录和揭晓进度保存在服务器。现场建议使用同一台导播设备，并提前在独立测试数据上完整联排。部署时应使用 HTTPS，以保证浏览器可以生成安全的抽奖请求编号。

新建数据库的默认号码范围是 1–2000。已有数据库继续使用保存的设置，部署到其他环境后应在抽奖设置页确认并保存号码范围；已打开的大屏需刷新后才会读取新设置。
