# 无间道抽奖

在后台的**抽奖设置**中保存票号范围和四档名额，然后打开 **抽奖导播台**（`/admin/lottery/display`）。新库默认范围是 0001–2000，四档默认名额依次是 30、10、3、1。新开奖支持 0000–9999。投影、导播、观众查询及 Excel 都显示四位票号，例如 0719。导播台打开时读取配置，在当前抽奖画面也能临时调整本场名额和名称。每档支持 1–100 名，实际可抽人数受剩余票号数量限制。

## 两场流程

| 场次 | 奖项 | 开奖画面 |
| --- | --- | --- |
| 第一场 | 三等奖 | 雨夜与接收机播完自动接读带机，停在绿屏待命。主持人喊滚号后按空格推入绿屏（约 1.1 秒）开始滚号，喊停后整批三十人按六列五行干脆定格。 |
| 第一场 | 二等奖 | 放大镜找到底片上的身影，蜡笔圈住目标并压紧玻璃后停住待命。按空格推入印相框（约 1.05 秒）滚号，喊停后十人分两排、每排五格快速显影定格。 |
| 第二场 | 一等奖 | 来电响铃播完自动接通并推向拾音表后停住待命（也可提前按空格切入）。按空格切入三联监听机柜（约 1.1 秒），2–6 人（默认 3 人）采用逐席滚动、逐席停号：第 1 窗滚动→喊停即刻定格（此时网站只公开第 1 位）→主持人念完再按空格即刻滚动第 2 窗，依此类推。 |
| 第二场 | 特等奖 | 手机合盖反光播完自动切入电梯门与天台走近、对白，镜头推近到双人黑色侧影并静候待命（不提前滚号）。按空格起号滚动（约 0.55 秒浮现），喊停后干脆定格并压暗窗光。 |

四档前奏都会连播完整剧情并在数字开始滚动前停住待命（主持人说词快时也可按空格提前推进），听到“滚动起来”按一次**空格**起滚，喊“停”时再按**空格**干脆定格。三等奖、二等奖和特等奖整批一次抽取并公开；一等奖为 2–6 人时在首席停号时由服务器一次抽取并去重，之后按席位逐个公开，刷新页面可恢复当前已揭晓进度，尚未停号的席位绝不提前泄漏到投影或观众页。重复确认、网络重试或另一导播窗口同时操作同一档，都会得到同一批结果。断网时画面继续滚号，恢复后重试即可。第一场停在幕间，第二场由导播继续推进。

## 导播与投影

在导播台点**打开纯净大屏**（`/admin/lottery/screen`），把新窗口移至扩展屏，按 F11 全屏。两个窗口须在同一台电脑、同一浏览器配置文件下访问相同的网站地址。大屏仅接收展示状态。音效从导播窗口输出，可将该电脑的音频送入现场调音台。

导播台的推进按钮跟随画面变化。前奏停稳后显示“进入滚号”；镜头推入期间显示“快进到滚号”；等按钮显示“确认开奖”（一等奖逐席模式下依次显示“确认开奖（第 1/3 位）”、“滚动第 2/3 位”等），再配合主持人口令按键。名单显现期间可选快进；回看已抽奖档时显示“揭晓原号码”。

| 导播快捷键 | 操作 |
| --- | --- |
| 空格、Enter、→ 或 Page Down | 前奏结束后进入滚号；推入期间快进到滚号；滚号时确认开奖（一等奖逐席模式交替执行“停号”与“滚动下一位”）；定格后再按进入下一幕 |
| ← 或 Page Up | 回到上一幕；一等奖若误触提前启动下一席滚号，按一次 ← 可退回当前已锁席位继续静候；在完整名单上回退可重看滚号并再显原号码 |
| 1 / 2 / 3 / 4 | 跳到相应奖项的入场 |
| R | 重看当前奖项的入场 |
| N | 修改当前尚未开奖的名额。Enter 或移出输入框提交有效值，Esc 取消。提交后投影一次调整到新名额 |
| M / F / H | 开关音效 / 切换全屏 / 收起或打开导播面板 |

刷新导播台会读取已开奖项，刷新投影会恢复当前画面。观众在 `/lottery` 查询，页面定期自动更新。后台可导出中奖记录。

特等奖名单定格后，可在名单或现场核验一幕处理失效票。单人场点“核券无效 · 重抽”，再按“确认开奖”。多人场先选择失效的四位票号，点“核券无效 · 重抽”。确认后该票撤出公开名单，投影只滚动该席，其他票号继续原位显示。主持人给出补抽口令时按“确认补抽”，替补号码回到原席。连接中断时重试同一次操作，刷新后可恢复待补席位。后台历史和导出保留作废票号与原因。所有已抽及作废号码都从后续抽取中排除。清空历史会一并重置四档开奖记录和号码池。

联排时，主持与导播使用[同一份台本](无间道联排主持与导播.md)。

升级前如有未完成的旧批次，请用原导播浏览器继续确认。既有中奖历史仍保留在数据库中并参与去重。
