# 无间道抽奖

在后台的**抽奖设置**中保存票号范围和四档名额，然后打开 **抽奖导播台**（`/admin/lottery/display`）。新库默认范围是 0001–2000，四档默认名额依次是 30、10、3、1。新开奖支持 0000–9999。投影、导播、观众查询及 Excel 都显示四位票号，例如 0719。导播台打开时读取配置，在当前抽奖画面也能临时调整本场名额和名称。每档支持 1–100 名，实际可抽人数受剩余票号数量限制。

## 两场流程

| 场次 | 奖项 | 开奖画面 |
| --- | --- | --- |
| 第一场 | 三等奖 | 指针停住，镜头靠近绿屏。第一道波峰留在画中，第二道波峰在读带机上接着写完后开始走带。候选票号占据绿屏主体，按口令在原位定格。三十人时排成六列五行。 |
| 第一场 | 二等奖 | 放大镜找到底片上的身影，蜡笔圈住人。底片随镜头滑进印相框，整批号码在同一张底片上显影。十人时分两排，每排五格。 |
| 第二场 | 一等奖 | 第一声铃亮起手机屏幕，第二声铃带动桌边仪表。镜头沿线移入监测仪，各通道就地锁号。三人时三个读数窗横向并列。手机合盖后的金属反光接上电梯门缝。 |
| 第二场 | 特等奖 | 先从门上反光看见来人，立柱后接上同一步。先到的人站稳，来人收步落肩。两侧剪影之间滚号，最后一位数字停住时窗光压暗。 |

每档只抽一次。导播推进至滚号，主持人发出口令后按一次**空格**。服务器在同一笔 SQLite 事务中抽取、去重、保存并公开整批号码。重复确认、网络重试或另一导播窗口同时抽同一档，都会得到同一批结果。断网时画面继续滚号，恢复后按“重试开奖”。第一场停在幕间，第二场由导播继续推进。

## 导播与投影

在导播台点**打开纯净大屏**（`/admin/lottery/screen`），把新窗口移至扩展屏，按 F11 全屏。两个窗口须在同一台电脑、同一浏览器配置文件下访问相同的网站地址。大屏仅接收展示状态。音效从导播窗口输出，可将该电脑的音频送入现场调音台。

导播台的推进按钮跟随画面变化。出现“快进到滚号”时，按下只会完成镜头推入。等按钮显示“确认开奖”，再配合主持人口令按键。名单显现期间可选“快进到完整名单”。回看已抽奖档时，按钮显示“揭晓原号码”。

| 导播快捷键 | 操作 |
| --- | --- |
| 空格、Enter、→ 或 Page Down | 镜头推入号码区时可快进到滚号。滚号时确认开奖。揭晓动画中可快进到完整名单，名单定格后再按进入下一幕 |
| ← 或 Page Up | 回到上一幕。在中奖名单上回退可重看滚号，再次揭晓会显示同一批号码 |
| 1 / 2 / 3 / 4 | 跳到相应奖项的入场 |
| R | 重看当前奖项的入场 |
| N | 修改当前尚未开奖的名额。Enter 或移出输入框提交有效值，Esc 取消。提交后投影一次调整到新名额 |
| M / F / H | 开关音效 / 切换全屏 / 收起或打开导播面板 |

刷新导播台会读取已开奖项，刷新投影会恢复当前画面。观众在 `/lottery` 查询，页面定期自动更新。后台可导出中奖记录。

特等奖名单定格后，可在名单或现场核验一幕处理失效票。单人场点“核券无效 · 重抽”，再按“确认开奖”。多人场先选择失效的四位票号，点“核券无效 · 重抽”。确认后该票撤出公开名单，投影只滚动该席，其他票号继续原位显示。主持人给出补抽口令时按“确认补抽”，替补号码回到原席。连接中断时重试同一次操作，刷新后可恢复待补席位。后台历史和导出保留作废票号与原因。所有已抽及作废号码都从后续抽取中排除。清空历史会一并重置四档开奖记录和号码池。

联排时，主持与导播使用[同一份台本](无间道联排主持与导播.md)。

升级前如有未完成的旧批次，请用原导播浏览器继续确认。既有中奖历史仍保留在数据库中并参与去重。
