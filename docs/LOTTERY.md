# 无间道抽奖

在后台的**抽奖设置**中保存票号范围和四档名额，然后打开 **抽奖导播台**（`/admin/lottery/display`）。新库默认范围是 1–2000，四档默认名额依次是 30、10、3、1。票号在投影和观众页均显示为七位。导播台打开时读取配置，在当前抽奖画面也能临时调整本场名额和名称。每档支持 1–100 名，实际可抽人数受剩余票号数量限制。

## 两场流程

| 场次 | 奖项 | 开奖画面 |
| --- | --- | --- |
| 第一场 | 三等奖 | 截获密电，镜头推入绿屏终端，滚动号码分组停在原位。 |
| 第一场 | 二等奖 | 打开机密档案，整批号码在接触印相纸上显影。 |
| 第二场 | 一等奖 | 接听来电，镜头移向监测仪，各通道依次锁定中奖号码。 |
| 第二场 | 特等奖 | 天台反光引出人物剪影，两侧侧影之间滚号并定格。 |

每档只抽一次。导播推进至滚号，主持人发出口令后按一次**空格**。服务器在同一笔 SQLite 事务中抽取、去重、保存并公开整批号码。重复确认、网络重试或另一导播窗口同时抽同一档，都会得到同一批结果。断网时画面继续滚号，恢复后按“重试开奖”。第一场停在幕间，第二场由导播继续推进。

## 导播与投影

在导播台点**打开纯净大屏**（`/admin/lottery/screen`），把新窗口移至扩展屏，按 F11 全屏。两个窗口须在同一台电脑、同一浏览器配置文件下访问相同的网站地址。大屏仅接收展示状态。音效从导播窗口输出，可将该电脑的音频送入现场调音台。

| 导播快捷键 | 操作 |
| --- | --- |
| 空格、Enter、→ 或 Page Down | 推进一幕，在滚号画面确认开奖 |
| ← 或 Page Up | 回到上一幕 |
| 1 / 2 / 3 / 4 | 跳到相应奖项的入场 |
| R | 重看当前奖项的入场 |
| N | 修改当前尚未开奖的名额，Enter 确认，Esc 取消 |
| M / F / H | 开关音效 / 切换全屏 / 收起或打开导播面板 |

刷新导播台会读取已开奖项，刷新投影会恢复当前画面。观众在 `/lottery` 查询，页面每 5 秒自动更新。后台可导出中奖记录。仅在确实无法核券的单人特等奖上，使用“核券无效 · 重抽”。作废号码仍计入去重，后台历史保留原因。清空历史会一并重置四档开奖记录和号码池。

升级前如有未完成的旧批次，请用原导播浏览器继续确认。既有中奖历史仍保留在数据库中并参与去重。
